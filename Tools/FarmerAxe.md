# 重斧农夫

从主菜单的“开始游戏”进入选角，第三个头像是重斧农夫。
人物使用现有 Farmer 2.png，待机、跑步、死亡动画通过 AcPlayer2 覆盖控制器接入。

基础配置：60 生命、5 移速；大斧头初始伤害 45、攻击间隔 1.5 秒、距离 2.2、角度 80°。
鼠标控制瞄准方向，扇形弧线中点朝向鼠标；蓄力、挥砍及收招全程跟随鼠标。自动按冷却挥砍，期间仍可移动和冲刺。常驻半透明范围提示，挥砍时变亮，与实际攻击共用原点、方向、半径和角度；距离与角度升级同步更新提示。
每次挥砍可命中扇形内多个敌人，每个敌人只受一次伤害；精英和 Boss 的击退较弱。
长柄斧的柄长等于扇形半径，距离升级只延长柄；柄粗细和斧刃保持人物像素比例，不再随距离等比放大。背包图标同步使用细长柄、小斧刃。
握点位于袖口下方，左右转身时镜像移动；小手覆盖柄端。武器、扇形提示和命中判定共用手部原点。

专属升级均为 3 级上限：
- 加长斧柄：每级距离 +0.4，斧头和弧光同步延长。
- 宽斧刃：每级角度 +15°，弧光覆盖同步扩大。
- 磨刀石：每级斧头基础伤害 +10，再计算通用攻击力加成。

尚有专属升级时，单人升级三选一至少包含一项；满级后退出候选池。
大斧头是专属初始武器，不会进入其他角色的普通武器/宝箱池。
同样开放在局域网角色选择中，并接入房主计算与现有 Sprite 快照同步。

## 调整和重建

- 角色参数：Assets/Resources/Data/PlayerData.json，id 3。
- 武器五级参数：Assets/Resources/Data/WeaponData.json，weaponID 103。
- 挥砍逻辑：Assets/Scripts/Weapons/AxeController.cs。
- 透明素材与切片：Assets/Resources/Sprites/FarmerAxe.png 及 .meta。
- 编辑器菜单 Tools/Farmer Axe/Rebuild Assets 可重建角色动画、图标、武器预制体和联机目录。

## 验证

已在 Unity 2022.3 编辑器中走通主菜单、三名角色选择及农夫开局，并检查头像、动画、中文描述和图标。
Tools/FarmerAxePlayChecks.cs 是可选的战斗集成检查，不在 Assets 中，也不会进入正式构建。
在 GameScene 使用未强化的农夫开局后，可通过 Unity Script Execute 执行该文件的 FarmerAxePlayChecks.Main。
它会临时固定玩家和敌人，运行实际挥砍，最后暂停游戏；结束后退出 Play Mode 即可恢复场景。
日志位于 Logs/FarmerAxe/play-checks.txt。

覆盖：前方多目标、重复碰撞体去重、侧后方和距离排除、暂停与冷却、三种升级的实际命中效果、
升级上限、武器等级叠加、候选池和联机资源目录。联机部分未运行第二个客户端的完整对战测试。
