## 方法与边界

两个独立 Windows 进程通过 127.0.0.1 通信；另用 Windows 构建作为房主、Unity Editor 作为加入者检查实际画面。
无头/隐藏窗口的屏幕截图可能为空，因此没有把隐藏窗口的黑色截图当作图像检查通过的依据。

端到端测试为保持可重复性，提高测试角色生命、生成指定经验掉落与 Boss，并验证它们经过正式游戏代码产生升级、救援与通关结果。
这不是一局未经干预的五分钟生存挑战，也不是双人难度平衡、长时间压力或高延迟网络测试。

尚未使用两台实体电脑验证实际 Wi-Fi、交换机隔离和防火墙环境。初版也未实现公网连接、断线恢复或本地移动预测。
